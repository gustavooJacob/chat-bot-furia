# 🦊 FURIA Fan Chat - Experiência Conversacional

Projeto desenvolvido para o processo seletivo da vaga de **Assistente de Engenharia de Software** na **FURIA Tech**.

## 🎯 Desafio

Criar uma interface conversacional para os fãs do time de CS:GO da FURIA. A proposta é oferecer um ambiente interativo onde o torcedor possa conversar com um "bot" sobre a equipe, seus jogos, conquistas e curiosidades.

---

## 🖥️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (puro)

---

## 🧠 Funcionalidades

- Interface de chat responsiva e estilizada com tema escuro inspirado na identidade visual da FURIA.
- O bot responde com base em palavras-chave presentes na mensagem do usuário.
- Animação de digitação do bot para dar sensação de conversa real.
- Respostas adaptadas a perguntas sobre:
  - Jogadores
  - Títulos e conquistas
  - Agenda de jogos
  - Apoio e torcida
  - Frases de incentivo à equipe

---

## 💬 Exemplos de Interação com o Chat

| **Usuário Pergunta**               | **Resposta do Bot**                         |
| ---------------------------------- | ------------------------------------------- |
| "Quem são os jogadores da FURIA?"  | Lista com os nomes e posições atuais.       |
| "Quando é o próximo jogo?"         | Resposta com data fictícia do próximo jogo. |
| "Quais títulos a FURIA já ganhou?" | Lista de títulos e anos.                    |
| "Eu sou fã da FURIA!"              | Resposta motivadora e de agradecimento.     |
